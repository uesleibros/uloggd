---
title: Paginação
description: Um objeto de página, em toda coleção.
---

Toda coleção responde `{ data, page }`:

```json
{
  "data": [],
  "page": {
    "number": 1,
    "size": 50,
    "total_items": 128,
    "total_pages": 3,
    "has_more": true
  }
}
```

Passe `?page=` para andar. As páginas começam em 1. Qualquer coisa fora de 1 a
1000 responde `400 invalid_request` em vez de uma página vazia, para que um laço
que perdeu a conta pare em vez de girar.

O catálogo é a única exceção no tamanho: pagina de 24 em 24 e trava na página
100, porque lê um índice de busca e não uma tabela.

```bash
curl "https://uloggd.com/api/v1/library?page=2" \
  -H "Authorization: Bearer ulg_live_..."
```

<Callout>
`has_more` sai do total, não do tamanho de `data`. Uma página que volta curta é
a última, mas o jeito honesto de perguntar é `has_more`.
</Callout>
