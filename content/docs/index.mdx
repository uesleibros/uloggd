---
title: uloggd API
description: Read and write a uloggd account from your own code.
---

A key resolves to the account that made it, and every request runs as that
account. A key can never do something its owner could not.

## Make a key

Open Settings, then Developer. Name the key, tick the permissions it needs and
create it. The token is shown once and stored only as a hash, so if you lose it
you make another.

## Your first request

```bash
curl https://uloggd.com/api/v1/me \
  -H "Authorization: Bearer ulg_live_…"
```

`/api/v1/me` needs no scope, so it answers for any live key and tells you what
that key holds.

## What stays true

Additive changes ship into v1. Anything that removes a field or changes what it
means waits for v2, and the two run side by side while v1 is deprecated.
