title: Premiações
description: Edições personalizadas com categorias, indicados e vencedores.
full: true
---

Cada edição pode usar o catálogo, uma lista do autor ou jogos registrados no ano. A lista base é acompanhada ao vivo: jogos removidos deixam de aparecer como indicados ou vencedores. Rascunhos são privados. O campo `version` impede que uma aba sobrescreva alterações mais recentes.
