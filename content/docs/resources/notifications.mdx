Cada notificação chega com o autor e com `path`, o endereço para onde
ela aponta. Resolver isso costumava ser trabalho de quem lê: onze
leituras encadeadas, porque o endereço de uma resposta é o endereço
do que ela responde mais uma âncora. É um join, e acontece onde os
joins acontecem.

`path` vem sem o prefixo de idioma — ele é de quem lê — e vem `null`
quando não há mais para onde ir.
