As cotas são contadas **por chave**, não por conta. Uma integração barulhenta não
consegue gastar a cota que o dono precisa para usar o site, e um script
desgovernado não tranca ninguém fora da própria conta.

## Cabeçalhos

Toda resposta carrega os números, inclusive as permitidas, para que um cliente
consiga desacelerar antes da parede em vez de depois.

```http
X-RateLimit-Limit: 600
X-RateLimit-Remaining: 597
X-RateLimit-Reset: 1788568502
```

`X-RateLimit-Reset` é um timestamp Unix ancorado na **chamada mais antiga da
janela**, não em agora. Ele não foge para frente conforme você insiste, então dá
para esperar uma vez em vez de recuar às cegas.

## Acima do teto

```json
{
  "error": {
    "code": "rate_limited",
    "message": "This key has used its allowance for now.",
    "retry_after": 118
  }
}
```

## O outro teto

Publicar uma imagem é contado duas vezes: uma na cota `write` da chave, que conta
requisições, e outra nas vinte imagens por hora da conta, que conta imagens. A
segunda é a que aperta, porque imagem custa processamento e armazenamento, não
uma linha.
