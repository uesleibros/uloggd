# Legal review before launch

The Terms of Use, Privacy Policy, Cookie Policy, Child Safety text, consent interface, retention practices, processing records, vendor agreements, and data-subject request process require review by qualified Brazilian counsel before launch.

The cookie interface reflects the current technical audit: Supabase authentication and Cloudflare Turnstile are necessary; no analytics or marketing tools are installed. Re-audit the site and update both the interface and policies before adding any optional script, cookie, SDK, or browser storage.
